# HydraFit

A simple daily health and habit tracker built with vanilla HTML, CSS, and JavaScript.

## Live Preview:

[Open HydraFit](https://rockinhera.github.io/HydraFit/)

## Features:

- Water intake tracker.
- Habit streak tracker.
- Calorie calculator.
- Light and dark mode.
- Data saved with local storage.
- Responsive layout.

## Built With:

- HTML
- CSS
- JavaScript
